# Pi 品牌图形

仅用于标识会话所用的 Agent，不作为 Coda 自身标志。商标归各自权利人所有。

- `pi.svg`：取自 Pi 官方标志 <https://pi.dev/logo-auto.svg>（Pi 的 README 使用的同一文件），保留路径几何，
  把三块的填色（`#F09082`、`#4D9ABF`、`#F1BE58`）统一换成黑色，画布裁成以标志为中心的正方形并定为 256 px。
  单色，清单里 `template: true`，随文字颜色着色。
- `pi.pdf`：由同一组多边形手写的等比矢量 PDF（256×256），清单的 `icon` 指向它。

提取日期：2026-10-18。
