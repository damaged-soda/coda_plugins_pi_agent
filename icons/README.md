# Pi 品牌图形

仅用于标识会话所用的 Agent，不作为 Coda 自身标志。商标归各自权利人所有。

- `pi.svg`：取自 Pi 官方标志 <https://pi.dev/logo.svg>，保留原有路径几何、留白比例与三块配色
  （`#F09082`、`#4D9ABF`、`#F1BE58`），加了一层黑色正方形底，画布定为 256 px。
  彩色图标，清单里不设 `template`，Coda 按原色显示，深浅色模式下都在黑底上。
- `pi.pdf`：由同一组多边形手写的等比矢量 PDF（256×256），清单的 `icon` 指向它。

提取日期：2026-10-18。
